# MODNet close-up: source_evidence_unavailable

База: `d923648d18ef91bc29c37468257194904da17072`, ветка `feature/category-manager`.

## Результат и границы

Ложный отказ получения исходных доказательств устранён для пригодных готовых
MODNet-масок close-up без bbox. Проверки потери материала не отключены.
**Это не гарантирует успешный preview для любой маски MODNet.** На доступной
копии настоящая нейросеть оставляет прозрачную дыру у правой чашки; no-bbox
путь теперь честно отклоняет её по `source_local_material_loss`.

## Причина и изменение

`checked_subject()` передаёт готовую no-bbox маску в
`validate_undetected_subject()`. Раньше проверка могла использовать только
`build_undetected_seed_mask()`, рассчитанный на безопасное обучение GrabCut.
Он требует почти одинаковый верхний цвет и отвергает согласованные однородные
нижние углы другого цвета. Такие условия избыточны для проверки уже готовой
маски крупного плана.

Добавлен `build_closeup_validation_seed_mask()` — только резервный источник
доказательств для MODNet, после базовых проверок alpha и неудачи строгого seed.
Фактическая маска должна занимать не менее 50% кадра и нижней 5% полосы.

- Верхние углы должны быть независимо однородны: p90 разброса RGB <=4;
  различие центров <=48, chroma <=8. Не менее 98% угловых образцов должны
  соответствовать модели своего оттенка.
- Допускается ограниченный перепад освещения одного фонового оттенка.
  Яркость кандидатов ограничена подтверждёнными образцами +/-6, chroma <=4.
- Нижние углы используются как фон только при независимой однородности и
  близости к верхней цветовой семье (яркость <=24, chroma <=6).
  Соответствующий отделённый фон должен быть связан с собственным образцом.
- Однородное тело/бельё внизу требует подтверждения материала в верхней
  центральной области. Новый сплошной цвет поставщика не объявляется телом.
  Нижний образец не может стать фоном, если ему противоречит совпадающий
  по цвету замкнутый исходный материал в верхнем центре.
- Сохранены разнообразие исходного материала и прежние ограничения
  `source_component_loss`, `source_local_material_loss`,
  `source_thin_material_loss`. Их пороги не увеличены.
- Сохранена отдельная проверка удаления надёжных углов; дополнительно
  проверяются внутренние области подтверждённого фона. Отказ остаётся
  `source_background_retained`.

Alpha не ремонтируется и не меняется. GrabCut продолжает использовать прежние
строгие seed. Bbox, товары без человека, geometry/crop, профили, размеры,
PHP, preview, интерфейс, CSRF не изменены. Новая полная внутренняя диагностика:
`mask_quality.modnet.source_evidence=closeup_corner_samples`.

## Проверка настоящей фотографии

Доступный файл: `20260904-111401-44eb8f1e1cbac540.jpg`, **1182x1536**, 268769 байт.
Это меньше указанного Android-оригинала 2500x3250; результат его нейросетевой
маски может отличаться. SHA-256 доступного файла:
`1bfd68d7dc5122a135ce0eede95ec3e93856eaacafcf9258ae40eee41d64957b`.

На этой копии верхние углы имеют разные бежевые оттенки (расстояние центров
31.10 на probe), а нижний правый угол — самостоятельный более тёмный фон.
Нижний левый угол — кожа. Следовательно, причиной `source_evidence_unavailable`
здесь был также запрет различий верхних оттенков, а не только нижних углов.

Среда: Linux, Python 3.12, OpenCV 4.14, ONNX Runtime 1.31, CPUExecutionProvider.
Использован штатный worker без подмены inference; проверены размеры и SHA
обеих моделей. MODNet: 25969398 байт,
`5069a5e306b9f5e9f4f2b0360264c9f8ea13b257c7c39943c7cf6a2ec3a102ae`;
MediaPipe: 11990159 байт,
`47fd5599d6fa17608f03e0eb0ae230baa6e597d7e8a2c8199fe00abea55a701f`.

С полным детектором на Linux найден bbox `[0,0,1182,1536]`, score 0.4923.
Этот существующий маршрут не проверяет `validate_undetected_subject()`.

У всех master 1200x1800, thumb 320x480; исходник и immutable-копии имеют

**Успех экспорта не доказывает отсутствие дефектов маски.** Визуально MODNet/Auto удаляют бежевый фон и в основном сохраняют тело/бельё, но остаётся светлая выемка над правой чашкой. GrabCut удаляет большую часть живота/левой руки и часть шеи/волос: такой результат непригоден. Это существующая bbox-ветка; её алгоритмы в задаче не менялись.

Отдельно воспроизведён требуемый no-bbox сценарий с недоступной моделью
детектора: реальные Haar/HOG и worker остались включены, ни один bbox не
получен. Также сделано прямое сравнение одного и того же реального alpha
со старым и новым валидатором.

|---|---|
| MODNet до изменения | `mask_quality_rejected / source_evidence_unavailable` |
| MODNet после изменения | `mask_quality_rejected / source_local_material_loss` |
| GrabCut | контролируемый `grabcut_mask_unavailable`, MODNet не запускался |

| Пригодная контрольная маска / Auto | MODNet принят, сменный фон применён |

Настоящий alpha имеет foreground ratio 0.862218 и теряет связный участок
203 пикселя на probe 394x512 при неизменном лимите 202. В исходном масштабе
это изолированная прозрачная область 1820 пикселей, bbox `[865,502,101,33]`,
над правой чашкой. Поэтому принимать её в no-bbox ветке небезопасно.

Только для контрольной проверки в памяти восстановлен этот единственный
участок alpha; RGB не менялся. Такой кандидат проходит неизменные проверки,
ratio 0.863220. Validator/composition не меняют входной RGBA.
**Это контролируемый кандидат, а не успешный исходный MODNet и не production
ремонт маски.** Никакая исправленная вручную фотография не опубликована.
Синтетический тест дополнительно подтверждает Auto: отказ строгого GrabCut
-> один пригодный MODNet -> Studio Light без фонового fallback.

После отказов новые original/processed каталоги и worker alpha очищены;
исходник не изменён.

## Финальная Android-проверка

1. Обновить **feature/category-manager** до коммита этого исправления через
   обычный GitHub Updater; перезапустить Python Image Processor.
2. Выбрать именно исходный файл 2500x3250, Studio Light, MODNet, создать
   новый preview. Старый preview не переиспользовать.
3. В деталях проверить: `subject_detected=false`, worker succeeded,
   `mask_quality.modnet.source_evidence=closeup_corner_samples`; для пригодной
   маски — status accepted / structural_checks_passed. Размеры прежние.
4. При увеличении проверить обе бретели, кружево правой чашки, кожу над ней,
   края тела и удаление верхнего/нижнего бежевого фона.
5. Повторить GrabCut и Auto. GrabCut может честно отказать
   `grabcut_mask_unavailable`; Auto должен использовать пригодный MODNet,
   а при настоящей потере материала сохранить честную причину fallback.
6. Если MODNet откажет по `source_local_material_loss`, сохранить новую
   диагностику и исходную alpha/preview. Это отдельный дефект сегментации;
   данный коммит намеренно его не скрывает ослаблением защиты.

Физический Android/KSWEB и точный исходник 2500x3250 здесь недоступны.
Цветовые признаки остаются консервативной структурной проверкой, не
семантическим доказательством принадлежности каждого пикселя.
Main и stash не изменялись, merge не выполнялся.
