# Ілюстровані смайлики для адмін-чату

У записі екрана показаний **спеціальний графічний набір Viber**, а не Unicode-емодзі.
Репозиторій Anabelka містить тільки словник **213 кодів/назв**, потрібний для
підключення зображень. Жодних зображень Viber або сторонніх брендів до публічного
GitHub не додано.

## Правомірні зображення

Можна використовувати лише PNG, для яких власник магазину має право на
відтворення та розповсюдження. Для оригінальних малюнків Viber потрібне
належне дозволене використання; сторонній репозиторій з кодом під MIT
**не передає автоматично прав на оригінальні картинки Viber**.

## Як активується

- Дозволені PNG-файли помістити локально у `assets/chat-emoji/graphics/`.
- Точні назви очікуваних файлів перелічено в `js/admin-chat-emoji.js`
  (об'єкт `window.AnabelkaChatClassicData.files`).
- Для активації потрібен **локальний** `manifest.json` з точними назвами наявних PNG,
  наприклад `{"version":1,"codes":["smiley","sad"]}`, разом із файлами
  `smiley.png` та `sad.png`. Коди перелічені в `js/admin-chat-emoji.js`.
  Якщо паку немає, відображаються лише звичайні Unicode-емодзі.
  Відсутні у списку маніфесту смайлики не показуються.
- Після появи дозволеного паку з'являються вкладки
  «Ілюстровані», «Обличчя», «Серця та жести» та інші.
- При натисканні додається текстовий код, наприклад `(smiley)`.
  **Після надсилання** код відображається як зображення для учасника,
  в якого встановлено той самий набір. Без зображення лишається текстовий код.
- Файли ігноруються Git через `.gitignore`. Для тестової копії
  `Anabelka-chat-test` треба окремо покласти дозволені файли в її папку.

Захищений від XSS рендеринг: HTML користувача не виконується, рядок
обробляється тільки як текст; картинки беруться за статичними іменами.
Перед релізом перевірити доступність зображень і права на їх використання.

## CH-EMOJI-02: другий оригінальний набір

Другий затверджений пакет додає **12 намальованих смайликів** до попередніх 12. Нові коди:
`shy`, `crying`, `sleepy`, `scared`, `party`, `confused`, `proud`, `tired`, `sick`, `cool`, `hug`, `sly`.
Палітра лише зі встановленого локального `manifest.json`, без мережевих CDN. Частина назв
(`shy`, `confused`, `sick`, `cool`) вже існує в таблиці 213 кодів,
інші 8 додані до словника. Зображення є оригінальними локальними PNG з прозорістю;
у GitHub вони не публікуються.

При встановленні потрібно зберегти перші 12 PNG, додати 12 нових файлів,
доповнити `manifest.json` без стирання старих кодів, та використовувати
`js/admin-chat-emoji.js?v=3` для оновлення кешу Chrome.
Спершу встановлювати тільки в ізольовану `Anabelka-chat-test`, після ZIP-бекапу.
Не змінювати MariaDB, механізм читання, фотографії або робочий магазин.
